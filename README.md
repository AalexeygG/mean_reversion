# Реконструкция биржевого стакана, анализ стратегии

## Что внутри

- **Реконструкция стакана** из MOEX Full Orders Log (Тип А) без отслеживания ID заявок.
- **Расчёт спреда** между mid-ценами SBER (спот) и SBERF (фьючерс) на 1-минутной сетке.
- **Стратегия Basis Mean-Reversion** с риск-фильтрами (торговое окно, фильтр резких движений, стоп-лосс, max hold).
- **Интерактивный дашборд** со слайдером времени и числовой панелью спреда.

## Результаты бэктеста


## Архитектурные решения

### Реконструкция стакана без ID заявок

MOEX-лог содержит три типа событий: `ACTION=1` (новая), `ACTION=0` (отмена), `ACTION=2` (исполнение). В отмене и исполнении сохраняются точная цена и объём — значит можно не трекать заявки по ID, а просто суммировать знаковые объёмы по уровням цены:

```python
df["_signed"] = np.where(df["ACTION"] == 1, df["VOLUME"], -df["VOLUME"])
```

Состояние стакана на момент T = `groupby(side, PRICE)["_signed"].sum()`, отфильтрованное по `volume > 0`.

### O(N) проход для построения временных рядов

`build_mid_series()` и `build_book_series()` идут по событиям ОДИН раз, накапливая словари `bids` и `asks`. На каждой границе snapshot-сетки (1 мин) записываем текущее состояние. Альтернатива (вызывать `get_snapshot()` на каждый бар) была бы O(N×M).

### Orphan-события из прошлой сессии

В логе встречаются `ACTION=0/2` без соответствующего `ACTION=1` (заявки из вчерашних сессий). Если их учитывать — volume уйдёт в минус. Решение: не удалять ключи из словаря, а на чтение фильтровать `v > 0`:

```python
best_bid = max((p for p, v in bids.items() if v > 0), default=None)
```

### Стратегия

Mean-reversion на базисе `SBERF − SBER`. Z-score нормирует отклонение спреда от 60-минутного скользящего среднего. Вход на ±2σ, выход с небольшим перехлёстом за среднюю (∓0.5σ) — это даёт ход 2.5σ ≈ 0.21 руб, против комиссий 0.12 руб запас прибыли ~75%.

Риск-фильтры подбирались с учётом trade-off на конкретных данных: жёсткий стоп 3.5σ срезал главную сделку дня (провал до −5.16σ полностью откатился), поэтому выбран 4.0σ — порог, который не сработал на этом дне, но защитит при реальном blow-up.

## Ограничения

- **Один день данных** — 12 сделок недостаточно для статистической значимости. WR=83% и PF=5.4 могут быть переоценкой; на большой выборке ожидать WR=55-65%.
- **Исполнение по mid-цене** — оптимистично; не учтён slippage и реальная вероятность fill для лимитных ордеров на экстремумах.
- **Маржинальные требования и стоимость фондирования** не моделируются.
